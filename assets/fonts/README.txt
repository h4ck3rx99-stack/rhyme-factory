FONTS (one-time, free, licensed for commercial use)
==================================================
Download and place the .ttf files in this folder:

  Fredoka-Bold.ttf         subtitles (SUB_FONT_NAME=Fredoka)        SIL Open Font License
      https://fonts.google.com/specimen/Fredoka  -> "Get font" -> "Download all"
      Unzip, open the "static" folder, copy Fredoka-Bold.ttf here.
      (The older "Fredoka One" also works if you already have it: set SUB_FONT_NAME=Fredoka One.)
  LuckiestGuy-Regular.ttf  title cards + thumbnails (TITLE_FONT_FILE)  Apache License 2.0
      https://fonts.google.com/specimen/Luckiest+Guy  -> "Get font" -> "Download all", unzip, copy the .ttf here.

Both licences allow use in videos and thumbnails. If either file is missing the helper
falls back to Arial Bold, which still works but looks less like a kids' show.
