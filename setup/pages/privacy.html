Rhyme Factory privacy policy

Last updated: 8 October 2026

What Rhyme Factory is

Rhyme Factory is a private, internal tool operated by Puddlehop Lane for one YouTube channel only: Puddlehop Lane (https://www.youtube.com/@PuddlehopLane). It creates original children's song videos and uploads them to that channel. It is not offered to the public and has no other users.

Which Google and YouTube data it uses

  • YouTube Data API: uploads videos, sets thumbnails and adds videos to playlists on the operator's own channel, and reads view, like and comment counts of that channel's own videos.
  • YouTube Analytics API: reads aggregate statistics (views, watch time, average view duration, subscribers gained) of the operator's own channel.
  • Google Sheets API: writes a production log and these statistics to a spreadsheet owned by the operator.

It does not access any other channel, any viewer's personal data, comments' content, or any data about children.

Storage and sharing

Data is stored only on the operator's own computer and in the operator's own Google Sheet. It is not sold, shared with third parties, or used for advertising. YouTube API data is refreshed or deleted within 30 days as required by the YouTube API Services Developer Policies.

Google and YouTube policies

Rhyme Factory uses YouTube API Services. By using YouTube you agree to the YouTube Terms of Service. See the Google Privacy Policy. You can revoke the tool's access at any time at Google security settings.
